### Process
Simple process for planning and executing a task backlog through a kanban style process.
Proccesses are keep in docs/backlog/**.  The backlog is BACKLOG.md, docs/DONE.md is completed tasks and docs/ADDITIONS.md are task deviations from the plan.
There is a lot of code quality support for this, including graphily.
